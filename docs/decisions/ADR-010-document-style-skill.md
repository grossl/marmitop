# ADR-010 — Document style skill

**Status:** accepted · 2026-10-13

## Question

The goal requires the "technical-writer" skill for every document. That skill is not installed in this environment.

## Choice

Use the installed `orwell-writing` skill. It applies the same baseline that the goal names: Orwell's six rules and ASD-STE100 Simplified Technical English. Code, commands, identifiers, and legal terms are not simplified.
